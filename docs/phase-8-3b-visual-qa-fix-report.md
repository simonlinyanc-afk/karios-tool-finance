# Phase 8.3B-Fix：Visual QA Fix for Theme Coverage & Export Preview Layout

## 1. 修复背景

Phase 8.3B 完成后，真实浏览器截图显示视觉验收仍未通过：浅色主题覆盖不完整，导出预览区域拥挤，左右辅助面板长期挤压主预览空间，预览不能缩放，版本记录侧栏仍保留硬深色样式。

本轮只修复 Phase 8.3B 暴露的视觉问题，不进入 Phase 8.4，不处理 v2.0.0 开屏升级弹窗。

## 2. 发现的问题

- 版本记录侧栏仍使用硬深色背景、灰色文字和固定边框色。
- 视觉复核补充意见指出：版本记录底部 `[ CLEAR ALL ] / AUTO-CLEANUP: 30 DAYS` 文案和红色按钮样式不适合当前用户界面。
- 视觉复核补充意见指出：上传图标右上角黄色小点没有明确功能，应去除。
- 视觉复核补充意见指出：上传区格式说明只保留第一句，文件数量和 PDF 页数提示下移为浅色辅助文字。
- 视觉复核补充意见指出：上传区“浏览器压缩 / 原始文件不会保存在服务器”说明删除。
- 视觉复核补充意见指出：页脚本地保存说明改为“数据仅保存在本地。”并增加“Powered by Qwen”。
- 视觉复核补充意见指出：浅色主题下 Header 需要使用深色 logo。
- 视觉复核补充意见指出：页脚版本号入口不需要胶囊外框，应作为普通文字角标保留点击能力。
- 视觉复核补充意见指出：导出预览侧边栏展开时，缩放工具栏会遮挡内容，需要隐藏。
- 报销单信息区的“版本记录 / CLEAN / SAVE”按钮仍保留旧深色与黄色按钮风格。
- 图片预览弹窗仍使用硬深色面板、工具条和导航按钮。
- 导出预览采用固定三栏结构，左侧列设置和右侧检查清单会挤压主预览区。
- 导出预览缺少缩放控制，无法适应不同屏幕宽度。
- Phase 8.3B 报告没有真实浏览器截图回归记录。

## 4. 主题覆盖修复内容

- 将版本记录侧栏替换为 `history-sidebar`、`history-card`、`history-action` 等 token 类。
- 将版本记录底部按钮改为“清空版本记录”，辅助说明改为“自动保留最近 30 天记录”，去除旧英文等宽按钮文案。
- 将报销单信息卡片头部、版本记录按钮、清空按钮、保存按钮改为 `modal-*`、`btn-secondary`、`btn-primary`。
- 将图片预览弹窗替换为 `image-preview-*` token 类。
- Header 在浅色主题使用 `assets/Kairos Finance Black.svg`，深色主题使用原浅色 logo。
- 上传图标去除无功能的 brandWarm 小圆点。
- 上传区主说明改为“支持 JPG、PNG、PDF。”，辅助说明改为“单次最多 10 个文件，PDF 默认识别第 1 页。”。
- 页脚说明改为两行：“数据仅保存在本地。”和“Powered by Qwen”。
- 页脚 `v2.0.0` 版本入口改为普通文字角标，保留点击查看版本信息能力。
- 保留 PDF / Excel 纸张预览中的白纸语义，用于表示真实导出页面，不作为主题缺陷处理。

## 5. 导出预览布局调整

导出预览改为“主预览优先”的结构：

- 顶部保留标题、Excel / PDF 切换和关闭按钮。
- 导出前检查由大卡片改为紧凑 chips：已完成、建议检查、识别失败。
- 左侧导出列设置改为可收起侧栏。
- 右侧检查清单改为可开合抽屉，默认不永久挤压预览区。
- 底部取消 / 导出按钮固定，不随内容滚动。

## 6. 预览缩放实现方式

新增统一缩放控件：

- 缩小
- 放大
- 当前比例
- 适应宽度
- 实际大小

缩放仅影响预览显示层，通过 `previewZoom` 控制预览 stage 的显示比例；真实 Excel 导出与打印调用仍保持：

- `window.exportToExcel(items, columns, reimbursementInfo)`
- `window.exportToPrint(items, columns, reimbursementInfo)`

## 7. 侧栏 / 检查清单收起逻辑

- 左侧列设置使用 `showColumnSettings` 控制展开 / 收起。
- 收起后仅保留窄按钮入口，主预览区自动扩大。
- 右侧检查清单使用 `showCheckDetails` 控制抽屉展开 / 收起。
- 有“建议检查”或“识别失败”时展示检查清单入口。
- 检查清单仅列出需要处理的条目，不显示大面积空面板。
- 缩放工具栏仅在列设置和检查清单都收起时显示，避免侧栏展开时遮挡内容。

## 8. 版本记录侧栏主题修复

- 浅色主题下：版本记录侧栏使用白色 surface、浅色边框和清晰文字。
- 深色主题下：版本记录侧栏使用深色 surface、克制边框和清晰文字。
- 空状态、关闭按钮、清空按钮均改为 token 样式。
