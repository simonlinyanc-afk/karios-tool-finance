# Kairos Finance v2.0.0 网页版本收尾报告

## 1. 本次网页版本更新范围

本次只处理网页版本展示和首次进入 v2.0.0 的升级说明：

- 将用户可见版本角标统一为 `v2.0.0`。
- 将内部包版本同步为 `2.0.0`。
- 更新网页开屏升级报告文案。
- 增加版本化已读标记，避免用户关闭后每次刷新重复弹出。
- 将页脚版权角标调整为 `Kairos Studio©️ 2026`。

未做功能重构，也未改动 OCR、鉴权、模型、导出、打印或部署核心逻辑。

## 2. v2.0.0 角标更新位置

| 位置 | 调整 |
| --- | --- |
| `data/version.json` | `version` 更新为 `2.0.0`，并承载 v2.0.0 开屏升级报告文案。 |
| `index.html` | 页脚版本按钮继续读取 `versionData.version`，因此显示为 `v2.0.0`。 |
| `package.json` | 包版本更新为 `2.0.0`。 |
| `package-lock.json` | 锁文件根包版本同步为 `2.0.0`。 |
| `README.md` | 增加“当前网页版本：v2.0.0”。 |
| `js/components/VersionModal.js` | 弹窗标题读取 `Kairos Finance v2.0.0 升级完成`。 |

## 3. 开屏升级报告展示逻辑

页面启动后继续加载 `data/version.json`。如果当前浏览器没有 v2.0.0 已读标记，则展示升级报告弹窗。

弹窗标题：

```text
Kairos Finance v2.0.0 升级完成
```

弹窗内容使用用户语言说明：

- 发票识别更稳。
- 需要检查的发票更容易看出来。
- 识别失败后可以重新识别、增强识别或手动填写。
- 导出前会提醒建议检查或识别失败的发票。
- 原始文件不会保存在服务器上。
- 导出前仍建议检查金额、税额、发票号码和日期。

弹窗按钮：

- `开始使用`
- `稍后查看`

开屏报告不展示工程词，包括 fallback、schema、JSON、MD5、IndexedDB、DashScope、model 等。

## 4. 已读状态保存方式

关闭 v2.0.0 开屏报告后，浏览器只写入：

```text
kairos-finance.seenUpgrade.v2.0.0=true
```

该标记只表示“当前浏览器已经看过 v2.0.0 升级说明”。它不保存：

- API Key
- OCR 访问凭证
- 发票内容
- base64 图片
- 原始发票文件
- 任何敏感凭证

## 5. 不改动的核心链路

本次未修改以下核心链路：

- OCR 模型路由。
- `/api/ocr` 鉴权逻辑。
- DashScope / Qwen 配置。
- Excel 导出逻辑。
- `print.html` 打印核心逻辑。
- Docker、Nginx、自托管部署核心逻辑。
- IndexedDB 本地缓存结构。
