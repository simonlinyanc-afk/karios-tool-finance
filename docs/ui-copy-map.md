# Kairos-Finance 界面文案映射

## 1. 写作原则

- 先说用户当前处境，再给下一步。
- 不承诺识别结果绝对准确。
- 不显示模型、结构协议、哈希、存储实现或服务商名称。
- 按钮使用明确动作，不使用“处理”“确定”“继续”等模糊词。
- 中文省略号统一使用 `…`。

## 2. 状态映射

| 内部状态或来源 | 禁止/旧文案 | 用户文案 | 用户下一步 |
| --- | --- | --- | --- |
| `queued` | 排队中 | 等待识别 | 可以取消该文件 |
| `processing` | OCR 中、处理中… | 正在识别 | 请稍候，或取消识别 |
| `ready` | 就绪、校验通过 | 已完成 | 导出前快速检查 |
| `needs_review` | 待检查、schema 校验失败 | 建议检查 | 展开条目并确认高亮字段 |
| `failed` | 失败、OCR 失败、JSON parse failed | 识别失败 | 重新识别、增强识别或手动填写 |
| `cached` | 缓存命中 | 已从本地记录恢复 | 检查或继续编辑 |
| `fallback` | fallback、兜底模型、二次调用 | 系统已自动再识别一次 | 检查本次结果 |
| `high_accuracy` | 高精度模型 | 增强识别 | 等待本次识别完成 |
| `manual` | manual entry | 手动填写 | 确认后保存 |
| `cancelled` | cancelled | 已取消 | 可重新选择文件 |

## 3. 上传与批量处理

| 场景 | 目标文案 |
| --- | --- |
| 上传标题 | 拖入发票，自动整理报销明细 |
| 上传说明 | 支持 JPG、PNG、PDF。单次最多 10 个文件，PDF 默认识别第 1 页。 |
| 隐私说明 | 系统会先在浏览器中压缩图片，再发送用于识别；原始文件不会保存在服务器。 |
| 准备图片 | 正在准备图片 |
| 等待 | 等待识别 |
| 识别中 | 正在识别发票 |
| 全部完成 | 识别完成，可以检查明细并导出。 |
| 有建议检查 | 识别完成，其中 {count} 张建议检查后再导出。 |
| 有失败 | 有 {count} 张暂时没有识别成功，可以重新识别或手动填写。 |
| 本地恢复 | 已从本地记录恢复 {count} 张发票，请检查后继续。 |
| 整批异常 | 本批次暂时没有完成识别。请检查文件格式后重试；仍然失败时可逐条手动填写。 |

## 4. 检查与恢复操作

| 当前状态 | 主按钮 | 次级按钮 |
| --- | --- | --- |
| 已完成 | 保存修改 | 快速检查 |
| 建议检查 | 确认无误 | 增强识别、手动修改 |
| 识别失败 | 重新识别 | 增强识别、手动填写 |
| 手动修改后 | 保存修改 | 恢复识别结果 |

识别记录文案：

- `已从本地记录恢复`
- `系统已自动再识别一次`
- `已使用增强识别`
- `已手动修改`

## 5. 错误文案

| 场景 | 目标文案 | 下一步 |
| --- | --- | --- |
| 文件过大 | 文件过大，暂时无法处理。 | 请重新导出较小的 PDF，或将发票截图后再上传。 |
| PDF 无法读取 | 这个 PDF 暂时无法读取。 | 请将发票页面截图后上传。 |
| 识别超时 | 识别时间过长，系统已停止等待。 | 请重新识别，或使用增强识别再试一次。 |
| 识别不完整 | 这张发票已识别出部分信息，但还有字段需要确认。 | 请检查高亮字段后再导出。 |
| 识别失败 | 这张发票暂时没有识别成功。 | 请重新识别、使用增强识别，或手动填写关键信息。 |
| 访问验证失败 | 当前访问未通过验证。 | 请确认你正在使用工作室内部提供的正确入口。 |
| 服务配置错误 | 识别服务暂时不可用。 | 请联系维护人员检查服务设置。 |
| 打印页未打开 | 浏览器没有打开打印页面。 | 请允许当前页面打开新窗口，然后再次点击打印。 |
| 导出库未就绪 | 暂时无法生成 Excel。 | 请刷新页面后重试；仍然失败时联系维护人员。 |

禁止把 `error.message`、HTTP 原文、服务商名称、文件路径或内部错误码直接拼入 toast、表格说明或导出内容。

## 8. 禁用词检查

以下词可以存在于内部代码、测试和高级技术文档，但不得出现在普通用户界面：

`fallback`、`schema`、`JSON`、`MD5`、`IndexedDB`、`DashScope`、`model`、`Bearer`、`Token`、`OCR 失败`、`缓存命中`、`Popup Blocker`、`Draft`。
